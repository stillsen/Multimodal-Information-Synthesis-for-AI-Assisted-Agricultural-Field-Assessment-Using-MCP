## Title

Multimodal Information Synthesis for AI-Assisted Agricultural Field Assessment Using Model Context Protocol

## Creators

- Stiller, Stefan (ORCID: 0009-0004-7468-1678), Leibniz-Centre for Agricultural Landscape Research (ZALF) e.V.

## Description

Software accompanying the study "Multimodal Information Synthesis for AI-Assisted Agricultural Field Assessment Using Model Context Protocol".

This deposit provides three MCP servers that expose complementary agricultural information modalities to LLM clients—(i) image-based crop yield prediction, (ii) topic-based access to scientific PDF literature, and (iii) soil laboratory and moisture CSV resources—together with Python code to regenerate the manuscript evaluation figures. The figures address two research questions: whether structured MCP access improves response quality relative to unstructured availability of the same sources, and whether increasing multimodal resource variety under MCP further improves response quality.

Large model checkpoints and raw experimental chat logs are not necessarily included; see the README for required local assets and path conventions. Related self-supervised yield-model code is available at https://github.com/stillsen/Self-Supervised-Learning-for-Crop-Classification-and-Yield-Prediction
